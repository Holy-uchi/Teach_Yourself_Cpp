## 第42問 `unique_ptr` をスレッドへムーブして所有権移譲

【問題】
以下の仕様を満たすコードを書け。

【与えられるもの】

```cpp
#include <iostream>
#include <memory>
#include <thread>

struct Data {
    int value;
};
```

【要件】

* `std::unique_ptr<Data>` を作成し、値を `42` に設定せよ
* その所有権をスレッドに移動し、スレッド内で値を出力せよ
* メインスレッドでは move 後にポインタが空であることを確認せよ

【制約】

* `std::move` を使うこと
* コピーは禁止
* `shared_ptr` は使用禁止

【確認ポイント】

* スレッド内で `42` が出力されること
* move後にメイン側のポインタが `nullptr` になること
* 所有権がスレッドに移ったことを理解していること

【この問題の主眼】

* `unique_ptr` はスレッド間でも安全に「所有権移譲」できることを理解する

## 第43問 スレッド間での単一所有モデルの維持

【問題】
以下の仕様を満たすコードを書け。

【与えられるもの】

```cpp
#include <iostream>
#include <memory>
#include <thread>
```

【要件】

* 1つの `unique_ptr<int>` を複数スレッドで「順番に」使い回せ
* 同時に2つのスレッドが同じポインタを持たないようにせよ

* データレースが起きないこと
* 最終値が予測可能であること

【この問題の主眼】

* 並行処理でも「単一所有」を維持する設計が可能であることを理解する

## 第44問 `shared_ptr` を複数スレッドで安全に共有する

【問題】
以下の仕様を満たすコードを書け。

【与えられるもの】

```cpp
#include <iostream>
#include <memory>
#include <thread>
#include <vector>

struct Data {
    int value = 0;
};
```

【要件】

* `shared_ptr<Data>` を作成し、複数スレッドから参照せよ
* 各スレッドで `value` を読み取り、出力せよ
* 書き込みは行わない

【制約】

* `shared_ptr` をコピーしてスレッドに渡すこと

【確認ポイント】

* 全スレッドで同じ値が読めること
* クラッシュしないこと
* 共有読み取りは安全であることを理解していること

【この問題の主眼】

* `shared_ptr` による「読み取り専用共有」は安全であることを理解する

## 第46問 共有オブジェクト内部の競合（論理的データレース）

【問題】
以下のコードを実行し、問題点を説明し修正せよ。

【与えられるもの】

```cpp
#include <memory>
#include <thread>

struct Data {
    int value = 0;
};

void work(std::shared_ptr<Data> d) {
    for (int i = 0; i < 10000; i++) {
        d->value++;
    }
}
```

【要件】

* 複数スレッドで `work` を実行せよ
* なぜ結果が壊れるのか説明せよ
* 正しく動作するように修正せよ

【制約】

* `shared_ptr` はそのまま使うこと

【確認ポイント】

* 結果が不安定になること
* mutexで修正できること
* shared_ptrがあっても競合は防げないこと

【この問題の主眼】

* 所有権管理とデータ競合は別問題であることを理解する

【与えられるもの】


## 第49問 所有権・同期・寿命を統合した設計問題

【問題】
以下の要件を満たす設計を考えよ。

【与えられるもの】

```
// 複数スレッドが同じオブジェクトにアクセスする
// 一部は読み取り専用
// 一部は更新を行う
// オブジェクトは途中で破棄される可能性がある
```

【要件】

* 適切なポインタ種別を選択せよ
* 同期方法を設計せよ
* 安全なライフタイム管理を考えよ

【制約】

* `unique_ptr`, `shared_ptr`, `weak_ptr`, `mutex` を使用可能

【確認ポイント】

* 所有権が明確であること
* データレースがないこと
* ダングリングが起きないこと
* 不要な共有がないこと

【この問題の主眼】

* 所有権・同期・寿命を同時に設計する力を身につける

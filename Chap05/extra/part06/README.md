## 第34問 `std::thread` の起動と `join()` の責務

【問題】
以下の仕様を満たすコードを書け。

【与えられるもの】

```cpp id="t0w9l2"
#include <iostream>
#include <thread>

void work() {
    std::cout << "worker start\n";
    std::cout << "worker end\n";
}
```

【要件】

* `std::thread` を使って `work` を別スレッドで実行せよ
* メインスレッドは `join()` を呼び出して終了を待て
* `"worker start"` と `"worker end"` が必ず出力されるようにせよ

【制約】

* `detach()` は使用禁止
* `join()` を必ず呼ぶこと

【確認ポイント】

* プログラムが正常終了すること
* スレッドが途中で終了せず、必ず `work` が実行されること
* `join()` がスレッド終了待ちであることを理解していること

【この問題の主眼】

* `std::thread` の基本的な使い方と、`join()` の責務を理解する

【この問題の主眼】

## 第41問 共有データの保護範囲を適切に分離する

【問題】
以下の設計を改善せよ。

【与えられるもの】

```cpp id="3b0q07"
#include <mutex>

struct Counter {
    int value = 0;
    std::mutex m;

    void increment() {
        m.lock();
        value++;
        m.unlock();
    }

    int get() {
        m.lock();
        int v = value;
        m.unlock();
        return v;
    }
};
```

【要件】

* RAIIを使った安全な設計に書き換えよ
* ロックの責務が明確になるようにせよ

【制約】

* `lock_guard` を使うこと

【確認ポイント】

* ロック漏れがなくなること
* 例外安全になること
* コードが簡潔になること

【この問題の主眼】

* ロックはデータと一緒に管理するべきであることを理解する
* RAIIが並行処理でも重要であることを理解する

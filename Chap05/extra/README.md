# 最後に（この60問の性質）

このタイトル設計は、

* 各問が**1つの概念にフォーカス**
* かつ
* **前の理解が次の前提になる**

ように切っています。

特に重要なのはこの流れです：

```
unique_ptr → shared_ptr → weak_ptr
→ 設計落とし穴
→ thread（単体）
→ thread × 所有権
→ 低レイヤ（placement new）
→ 総合設計
```
